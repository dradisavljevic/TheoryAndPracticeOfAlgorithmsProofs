\noindent \textbf{Exercise 12.a)}  Non-uniform circuit families are unexpectedly powerful, since they can also ``compute'' non-computable functions like the halting problem.
\begin{proof}
The power of non-uniform circuits comes from the fact that they allow a different circuit for each input size, without requiring a uniform construction algorithm.

Consider encoding an instance of the halting problem as follows: For each fixed input length $n$, we encode:
\begin{itemize}
\item The binary representation of a Turing machine description (first $k$ bits)
\item The binary representation of an input to that machine (remaining $n-k$ bits)
\end{itemize}

For a uniform family of circuits, we would need a single algorithm (Turing machine) that, given $n$, outputs the circuit $C_n$ for that input length. Since the halting problem is undecidable, no such algorithm can exist.

However, a non-uniform circuit family $(C_n)_{n \in \mathbb{N}}$ has no such requirement. For each $n$, the circuit $C_n$ is given independently without any constructive procedure. We can therefore define $C_n$ to correctly solve the halting problem for all instances that fit in $n$ bits, even though no algorithm generates these circuits.

Specifically, the circuit $C_n$ could be designed with the answer to the halting problem hardcoded for all instances of size $n$. This is possible because:
\begin{enumerate}
\item For each fixed $n$, there are only finitely many problem instances.
\item A circuit can be designed to output the correct answer for each specific instance (via lookup tables or hardcoded logic).
\item No algorithm is required to construct these circuits.
\end{enumerate}

Thus, non-uniform circuits can ``compute'' uncomputable functions because they bypass the uniformity requirement that enforces algorithmic constructibility.
\end{proof}ing, tikz, mdframed}

\begin{definition}
\textbf{Boolean Circuit -} A Boolean circuit $C$ with $n$ inputs and $m$ outputs is a finite acyclic directed graph whose nodes are marked as follows: 
\begin{itemize}
\item All nodes with in-degree $0$ are marked by $x_{1}, \ldots, x_{n}$ or constants $0$, $1$ (input nodes). 
\item Nodes with in-degree $1$ are marked by $\lnot$ (logical negation). 
\item Nodes with in-degree $2$ are marked by either $\land$ or $\lor$ (logical AND and OR, respectively). 
\item There are no nodes with in-degree greater than $2$. 
\item Exactly $m$ nodes have out-degree $0$ and are marked by $y_{1}, \ldots, y_{m}$ (output nodes).
\end{itemize}

It is assumed that there is at least one path from every input node to an output node. 

The circuit $C$ computes a function $f: \{ 0, 1 \}^{n} \rightarrow \{ 0, 1 \}^{m}$ as follows: Each input $x_{i}$ (for $1 \leq i \leq n$) is assigned a value $\nu (x_{i}) \in \{ 0, 1 \}$ representing the $i$-th bit of the input. Every other node $v$ is assigned a value $\nu (v) \in \{ 0, 1 \}$ obtained by applying the logical function marking node $v$ to the value(s) of the nodes with edges pointing to $v$. The function value is the tuple $(\nu(y_{1}), \ldots, \nu(y_{m}))$, where output node $y_{j}$ (for $1 \leq j \leq m$) contributes the $j$-th bit of the output.
\end{definition}


\begin{definition}
For measuring the complexity of a Boolean circuit $C$ we use the depth of $C$ defined as the length of the longest path from an input node to an output node (parallel time) as well as the size of $C$ given by the total number of nodes (parallel amount of hardware).
\end{definition}


\begin{definition}
\textbf{Boolean Circuit Family -} A Boolean circuit family $(C_{n})_{n \in \mathbb{N}}$ is a sequence of circuits, where each $C_{n}$ computes the function $f_{C_{n}}: \{ 0, 1 \}^{n} \rightarrow \{ 0, 1 \}^{m(n)}$. The function $f$ computed by $(C_{n})_{n \in \mathbb{N}}$ is defined as
$$f_{C}: \{ 0, 1 \}^{*} \rightarrow \{ 0, 1 \}^{*}$$
where $f_{C}(x) =_{df} f_{C_{|x|}}(x)$.
\end{definition}

\noindent \textbf{Exercise 12.b)} Let $(P, G) \oplus (P', G') = (P \land P', G' \lor (P' \land G))$ denote a binary operation on pairs. Prove that $\oplus$ is associative.
\begin{proof}
We prove that $\oplus$ is associative by computing both sides of the associativity equation and verifying they are equal.

\textbf{Definition:} $(P, G) \oplus (P', G') = (P \land P', G' \lor (P' \land G))$

\textbf{Properties used:}
\begin{itemize}
\item Associativity of $\land$ and $\lor$: $(a \land b) \land c = a \land (b \land c)$ and $(a \lor b) \lor c = a \lor (b \lor c)$
\item Distributivity: $(a \lor (b \land c)) = (a \lor b) \land (a \lor c)$ and $(a \land (b \lor c)) = (a \land b) \lor (a \land c)$
\item Absorption: $(a \lor (a \land b)) = a$ and $(a \land (a \lor b)) = a$
\end{itemize}

\textbf{Left-hand side:} $[(P_0, G_0) \oplus (P_1, G_1)] \oplus (P_2, G_2)$

Step 1: Apply $\oplus$ to $(P_0, G_0)$ and $(P_1, G_1)$:
$$(P_0, G_0) \oplus (P_1, G_1) = (P_0 \land P_1, G_1 \lor (P_1 \land G_0))$$

Step 2: Apply $\oplus$ to the result and $(P_2, G_2)$:
$$[(P_0 \land P_1), (G_1 \lor (P_1 \land G_0))] \oplus (P_2, G_2)$$
$$= ((P_0 \land P_1) \land P_2, G_2 \lor (P_2 \land (G_1 \lor (P_1 \land G_0))))$$
$$= (P_0 \land P_1 \land P_2, G_2 \lor (P_2 \land G_1) \lor (P_2 \land P_1 \land G_0))$$

\textbf{Right-hand side:} $(P_0, G_0) \oplus [(P_1, G_1) \oplus (P_2, G_2)]$

Step 1: Apply $\oplus$ to $(P_1, G_1)$ and $(P_2, G_2)$:
$$(P_1, G_1) \oplus (P_2, G_2) = (P_1 \land P_2, G_2 \lor (P_2 \land G_1))$$

Step 2: Apply $\oplus$ to $(P_0, G_0)$ and the result:
$$(P_0, G_0) \oplus [(P_1 \land P_2), (G_2 \lor (P_2 \land G_1))]$$
$$= (P_0 \land (P_1 \land P_2), (G_2 \lor (P_2 \land G_1)) \lor ((P_1 \land P_2) \land G_0))$$
$$= (P_0 \land P_1 \land P_2, G_2 \lor (P_2 \land G_1) \lor (P_1 \land P_2 \land G_0))$$

\textbf{Comparison:}

Both sides simplify to:
$$(P_0 \land P_1 \land P_2, G_2 \lor (P_2 \land G_1) \lor (P_2 \land P_1 \land G_0))$$

The first components are identical: $P_0 \land P_1 \land P_2$.

The second components are equal because the expressions:
$$G_2 \lor (P_2 \land G_1) \lor (P_2 \land P_1 \land G_0)$$
both appear on the right-hand side and are the same due to associativity and commutativity of $\lor$.

Therefore, $[(P_0, G_0) \oplus (P_1, G_1)] \oplus (P_2, G_2) = (P_0, G_0) \oplus [(P_1, G_1) \oplus (P_2, G_2)]$, and $\oplus$ is associative.
\end{proof}
